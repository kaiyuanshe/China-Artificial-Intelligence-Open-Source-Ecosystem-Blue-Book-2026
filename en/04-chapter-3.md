**Chapter 3: The development of China's open source AI ecosystem**

**3.1 Core elements of the open source AI ecosystem**

**An open source AI ecosystem is an interconnected system of AI innovation organized around open source AI projects. It comprises five core elements: ecosystem participants, open source artifacts and tooling, collaboration networks, governance arrangements, and the broader enabling environment. These elements are interdependent, mutually reinforcing, and evolve together.**

Within this ecosystem, an **open source AI project** refers to an organized process through which contributors use particular AI technologies and artifacts to pursue defined project objectives. Such projects serve as the ecosystem's organizing hubs. **Open source artifacts and tooling** include large-scale AI models, datasets, training and inference code, AI development systems and toolchains, and software composition analysis (SCA) tools. Together, they form the technical foundation of the open source AI ecosystem.

+--------------------------------------------------------------------------------------------------------------------------+
| **Case Study: Open source artifacts and tooling — Awesome Public Datasets, from university research to global data       |
| curation**                                                                                                               |
|                                                                                                                          |
| The Awesome Public Datasets project was incubated by the OMNILab team led by Professor Jin Yaohui at Shanghai Jiao Tong  |
| University. It was originally developed to meet researchers' need to systematically identify and access high-quality     |
| datasets for research in urban computing and large-scale data mining. The project has since grown into one of the        |
| world's largest platforms for curating open datasets, with more than 70,000 GitHub stars, more than 155 contributors,    |

|                                                                                                                          |
| Its technical distinction lies in the apd-core automated curation engine, which uses a "metadata-driven" contribution    |
| model and manages dataset entries through standardized YAML metadata, ensuring link validity and content quality. The    |
| project has become a core part of the "Baiyulan Open Source AI Community" (supported by the Shanghai Municipal           |
| Commission of Economy and Informatization) and has been adopted by many universities worldwide as a core resource for    |
| data science courses, embodying the typical evolution of open data infrastructure from academic incubation to community  |
| governance.                                                                                                              |
+--------------------------------------------------------------------------------------------------------------------------+

**The participants in an open source ecosystem include** open source contributors, open source users, open source operators, open source service providers and open source governance bodies, among others. Open source contributors are the enterprises, research institutions, public organizations or individuals that contribute open source projects and open source artifacts and tooling; open source users are the users of those projects and artifacts. Open source operators are the operating entities that promote interaction and collaboration among contributors and effective connections between contributors and users. Typical examples include Hugging Face internationally and ModelScope, Modelers and Huanxin in China, which build AI open source ecosystems by bringing together and efficiently allocating key elements such as computing power, models, data and talent.

+--------------------------------------------------------------------------------------------------------------------------+
| **Case Study: ModelScope**                                                                                               |
|                                                                                                                          |
| The ModelScope community is an AI model open source community launched by Alibaba together with the Open Source          |
| Development Technical Committee of the China Computer Federation (CCF) in 2022, positioned as an open source platform    |
| focused on multimodal AI models. On the one hand, ModelScope provides services covering the path from model training to  |
| deployment, including computing support, data hosting, toolchain development, development tools and deployment; on the   |
| other hand, it connects enterprises, universities, social organizations and individual developers in a wide range of     |
| competitions, R&D and educational activities, driving model development, aggregation and industrial deployment. As of    |
| March 2026, ModelScope had brought together more than 170,000 open source models and more than 9,000 MCP services,       |
| serving users in more than 200 countries and regions, making it the largest model open source community in China and one |
| of the world's leading model platforms. Leading models from organizations including DeepSeek, Tencent, StepFun, MiniMax, |
| Kimi and Shanghai AI Laboratory have all been open-sourced on the platform.\[22\]                                        |
+--------------------------------------------------------------------------------------------------------------------------+

**Open source service providers** are the service entities that provide supporting services to open source projects and the parties involved. Typical examples in China include Datawhale and the X-lab at East China Normal University, which support developers' capability growth and the spread of projects through competitions, course-based training, developer events, and open source assessment and consulting services. **Open source governance bodies** are the entities that formulate and implement the policies or rules that promote and regulate the development of the open source ecosystem; typical examples include the Linux Foundation internationally and the OpenAtom Foundation and local governments in China.

Open source contributors, users, operators, service providers and governance bodies constitute the core of the AI open source ecosystem.

The **open source network** comprises the interaction channels, relational structures, and collaborative mechanisms through which the open source ecosystem participants connect with one another and with open source projects. It forms the connective fabric of the open source AI ecosystem. Unlike the relatively loose, repository-centered collaboration networks associated with traditional open source software development, open source AI networks typically have complex, multi-layered structures spanning multiple roles and platforms. These networks take a variety of organizational and infrastructural forms, including project communities, platform-based communities, model-hosting platforms, industry alliances, and foundation-based governance structures. In structural terms, open source AI networks occupy a continuum ranging from decentralized to highly centralized configurations and evolve in response to changes in technological maturity, governance mechanisms, and commercial objectives.

**Open source governance** refers to the ecosystem rules of an open source system and their implementation, including open source licenses and community management rules; it is the support of the AI open source ecosystem. The open source license is a legal safeguard for the core idea of open source, ensuring that open source projects can be freely used and shared lawfully. It is the key to resolving the tension between the exclusivity of intellectual property and the sharing of source code. For developers, an open source license grants rights such as the right of publication and the right of attribution, which acts as an incentive; for users, it helps them avoid possible legal disputes such as infringement; and for the open source ecosystem as a whole, it defines the rights and obligations of ecosystem participants and is the core rule of ecosystem operation, promoting the well-regulated development of open source projects.

The **open source ecosystem environment** refers to the broader economic, social, political, and cultural context in which an open source ecosystem operates. It includes factors such as the level of local economic development, industrial structure, the concentration of technology companies and skilled talent, and government policy priorities. Collectively, these factors constitute the external environment shaping the open source AI ecosystem.

**It is worth noting that, unlike governments in many other countries, the Chinese government has long played an important role in market development and ecosystem building. Within China's open source AI ecosystem, it serves as a provider of services, an ecosystem operator, and a governance actor. The ways in which these roles are defined, positioned, and performed — and the relative emphasis placed on each — vary across regions, reflecting differences in their open source ecosystem environments.**

**3.2 Ecosystem models of AI open source projects**

In general, along two dimensions — collaboration model and governance intensity — the ecosystem models of AI open source projects can be divided into four types: the single-organization-led model, the peripheral-ecosystem model, the standard-exploration model and the neutral-governance model.

China's AI open source projects show a markedly uneven distribution across these models: the single-organization-led and peripheral-ecosystem models predominate, while the standard-exploration and neutral-governance models are relatively few and still at an early stage of development.

**The single-organization-led model** is an open source AI ecosystem model in which a single company or institution takes the lead, releasing code, models, or technical capabilities in order to expand its own technology ecosystem. Under this model, ownership of project intellectual property, control over the development roadmap, and authority over resource allocation are highly concentrated in the lead organization. The community functions primarily as a channel for bringing users together and gathering feedback. In this arrangement, open source is used to support the industry platform's commercial strategy by attracting users and generating leads, creating ecosystem-based competitive barriers, and building brand recognition. The model is explicitly oriented toward commercialization. Its network structure is markedly centralized. The relationship between the industry platform and the project community more closely resembles vertical collaboration along an industry value chain than one based on joint development and shared governance. In some cases, the project community is itself part of the industry platform. This model enables highly efficient resource allocation and offers substantial advantages in commercialization and scaling. It responds to the industry's practical demand for efficiency and predictability and is currently the predominant model in China's open source AI ecosystem.

+--------------------------------------------------------------------------------------------------------------------------+
| **Case Study: Qwen**                                                                                                     |
|                                                                                                                          |
| Qwen is a series of general-purpose large models that Alibaba Cloud has released since 2023, with open weights, the full |
| pipeline code and published data construction methods. Alibaba Cloud leads in providing models, training and engineering |
| capabilities, releasing, iterating and governing through official repositories and official channels, with community     |
| participation mainly in the form of usage, adaptation, feedback and secondary development. Its business model is a dual  |
| track of "open source models + commercial APIs and platform services on the cloud": on the open source side, GitHub      |
| repositories and ecosystem adaptation (such as deployment, fine-tuning and toolchains) serve developer use and           |
| collaboration; on the distribution side, models are listed on communities such as ModelScope and Hugging Face to broaden |
| their reach; and on the commercial and engineering side, Alibaba Cloud Model Studio provides online experiences, a model |
| marketplace and API services that productize model capabilities into billable, operable service interfaces. As of May    |
| 2024, the Qwen large model served more than 90,000 enterprises through Alibaba Cloud and more than 2.2 million           |
| enterprises through DingTalk\[24\], with cumulative downloads of more than 7 million on open source communities such as  |
| Hugging Face and ModelScope\[25\] and a peak annual OpenRank score (a metric of open source community influence) of over |
| 1,600\[26\], forming a flywheel of "open source influence → developer adoption → enterprise conversion". When releasing  |
| Qwen 2.5, Alibaba Cloud also emphasized that its large-parameter open source models achieved leading results on several  |
| benchmarks, reinforcing a single-organization-led expansion strategy of "driving the ecosystem to follow through         |
| evaluations and release cadence".                                                                                        |
+--------------------------------------------------------------------------------------------------------------------------+

The **peripheral-ecosystem model** is an open source AI ecosystem model organized around open source artifacts and tooling, application frameworks, or workflows. By building on established mainstream technology stacks or platform ecosystems, projects following this model can spread rapidly. The model exhibits a relatively low degree of centralization: its contributor community is large and active, but contributions are largely confined to peripheral activities and innovations, such as developing plugins and adaptations, as well as providing user feedback, while the project initiator or a small core team retains control over the core architecture and development trajectory. The model emphasizes lowering barriers to adoption and improving the user experience, enabling projects to rapidly expand their influence. However, such projects often have difficulty establishing an independent center of technical leadership and governance, and are oriented more toward technology diffusion and the scaling of applications. Projects of this type are currently widespread in China and provide an application-oriented model for accelerating the integration of AI technologies into industry.

+--------------------------------------------------------------------------------------------------------------------------+
| **Case Study: Cherry Studio**                                                                                            |
|                                                                                                                          |
| Cherry Studio is released as open source and maintained by CherryHQ on GitHub. It is a cross-platform desktop AI client  |
| that provides access to multiple models and offers a suite of AI tools covering end-to-end workflows. It supports        |
| integration with more than 300 widely used models and is designed to provide an "out-of-the-box" cross-platform          |
| experience requiring no environment configuration. As of the time of writing, its GitHub repository had received more    |
| than 40,000 stars. Community contributions focus largely on peripheral features and improvements, including themes, UI   |
| plugins, utility tools, documentation, minor refinements, and fixes for edge cases. The core architecture, roadmap, and  |
| release process remain primarily under the control of CherryHQ and the project's core maintainers. In commercial terms,  |
| the Community Edition serves as both a technology showcase and a user-acquisition channel, while the Enterprise Edition  |
| generates revenue through customized solutions and value-added services.                                                 |
+--------------------------------------------------------------------------------------------------------------------------+

The **standard-exploration model** is an open source AI ecosystem model organized around general-purpose frameworks, methodologies, or abstract technical paradigms. Through open collaboration, it seeks to explore potential industry standards and build technical consensus. Projects following this model typically develop iteratively around a core architecture, attracting contributors from different organizations and technical backgrounds to participate in the design of key capabilities and discussions about the project's future direction. Collaboration focuses on the core capabilities themselves rather than on the expansion of peripheral applications. Community discussion is intensive, with strong competition among alternative technical approaches. Structurally, the model is relatively decentralized but not yet fully institutionalized. Its governance relies primarily on informal consensus, reflecting its distinctly exploratory character. Projects following this model remain relatively few in China. The model represents an exploratory approach to advancing industry-wide technological paradigms and standards in the country.

+--------------------------------------------------------------------------------------------------------------------------+
| **Case Study: CAMEL AI**                                                                                                 |
|                                                                                                                          |
| CAMEL AI is a community-led open source multi-agent framework released on GitHub in 2023. The paper introducing the      |
| framework was accepted to the main conference track at NeurIPS 2023. Built on large language models (LLMs), including    |
| those underlying ChatGPT, CAMEL AI serves as both an experimental platform and a development framework for multi-agent   |
| collaboration, with an emphasis on methodological exploration and innovation in application paradigms. Its core ideas    |
| were disseminated through the coordinated release of the research paper and source code. Drawing on growing research     |
| interest, the project established a dissemination pathway of "research–implementation–community replication" and has     |
| attracted more than 10,000 GitHub stars, becoming a widely referenced open source framework in the multi-agent field. It |
| has also served as a methodological reference for subsequent agent frameworks, including AutoGPT-style projects. Its     |
| business model remains at an exploratory stage. Eigent, a product built on CAMEL, is exploring enterprise applications   |
| such as customer relationship management (CRM) automation while developing agent runtime infrastructure and synthetic    |
| data generation technologies to provide services to model providers.                                                     |
+--------------------------------------------------------------------------------------------------------------------------+

The **neutral-governance model** is an open source AI ecosystem model in which a foundation or comparable neutral body provides the institutional home for the project's intellectual property and governance authority, while multiple stakeholders jointly develop and maintain the project. The model emphasizes neutral governance and institutionalized collaboration. Its core projects are typically organized into multiple modules or working groups, with different organizations or teams responsible for their respective components. Its network structure is polycentric and distributed: community members serve not only as users but also as contributors and maintainers of individual subsystems. The model aims to develop public infrastructure and industry-wide standards, prioritizing long-term stability and ecosystem resilience while seeking to balance technological evolution with organizational collaboration. Because decision-making and resource allocation can be less efficient, while governance and institutional development are costly and difficult, projects following this model have expanded relatively slowly in China. Nevertheless, the model represents a potential direction for the future development of China's open source AI ecosystem.

**3.3.2 Representative cities in the development of China's AI open source ecosystem**

Overall, China's urban AI open source ecosystems show a pattern of regional concentration led by leading technology companies. Although local governments across the country have rolled out related policies under the guidance of the State Council's AI Plus policy, in practice only Beijing, Shanghai, Shenzhen and Hangzhou show a visible AI open source ecosystem model (or its prototype), which is closely related to the concentration of high-tech companies and the high density of AI talent in those cities; other regions are still at the stage of initial awareness or construction planning. Clearly, the degree of participation and the focus of local governments in developing AI open source ecosystems are highly correlated with local resource endowments, industrial structure, economic development level and style of governance.

**3.3.2.1 Beijing: strengthening research as an innovation source, advancing self-reliance and controllability, setting a national benchmark**

Beijing is one of the most representative and most "native" innovation hubs for AI development in China, combining research leadership, a concentration of talent, industrial scale and a collaborative application ecosystem. [Beijing's core AI industry is expected to reach RMB 450 billion in 2025, with more than 2,500 AI-related companies](https://fgw.beijing.gov.cn/gzdt/fgzs/mtbdx/bzwlxw/202601/t20260129_4474702.htm?utm_source=chatgpt.com)\[27\]. The number of registered large models leads the country at more than 200, and the layout of its technology system covers the whole chain from basic theory and model building to application deployment. Many leading enterprises — Douyin, Baidu, Zhipu AI, Moonshot AI, Cambricon, Kunlunxin and others — contribute to this effort, and the national-level AI application Doubao has more than 170 million monthly active users. This reflects the combined results of Beijing's long-term work on technology innovation, talent aggregation and policy guidance, and the path it has taken to build its AI open source ecosystem is closely bound up with them.

**First, research as the source of innovation: driving foundational innovation to serve self-reliance and controllability and domestic substitution.** As China's national center for science and technology innovation, Beijing has dense resources in universities, research institutes and leading technology companies, forming the country's strongest talent hub environment: Beijing-based scholars account for about 40% of China's entrants on the AI2000 list of the world's most influential scholars, and about 30% of all AI experts in the country. Building on this depth of talent, *[Beijing Municipal Implementation Plan for Building the Open Source Ecosystem (2026–2028)](https://www.ncsti.gov.cn/zcfg/zcwj/202512/t20251225_233382.html)* places open source in the context of tackling "foundational software, industrial software and the foundational common technologies of artificial intelligence" and emphasizes open-sourcing common components, "building a full-stack in-house open source toolchain covering data preparation, model training and fine-tuning, inference deployment and performance evaluation". It also sets out a path of root open source community → in-house domestic products → large-scale application, encouraging key industry users and state-owned enterprises to build controllable, substitutable domestic products on an open source basis and deploy them. It promotes an open source hardware and software foundation platform for the fifth-generation reduced instruction set architecture (RISC-V) to break the current chokepoint in chips. This fully reflects Beijing's character as the national center for science and technology innovation and a gathering place for leading universities and national strategic science and technology forces.

**Second, leading technology platforms as the hub: building a nationwide open source hub and a large-scale ecosystem network.** In policy, Beijing places more emphasis on building platform infrastructure that integrates "hosting for open source large model R&D, heterogeneous computing scheduling and community operations", and uses industry funds and government-guided funds to increase its backing for open source large models and communities. Its goal is to make Beijing an influential open source node nationally and globally (including the vision of building a Chinese "Hugging Face")\[28\], which matches its industrial structure of concentrated headquarters of leading technology companies and strong cloud and large model platform capabilities.

**Third, foundation-layer engineering as the lever: turning open source into national industrial capability through data, computing power, use cases and organizational systems.** Beijing's policies include high-quality datasets, corpus standards and computing vouchers in the "basic supply" of the open source ecosystem, and use an organized diffusion mechanism of "demonstration by state-owned enterprises + opening up by large enterprises + follow-up by small and medium-sized enterprises and incubators" to drive large-scale application and demonstration effects of open source solutions in key industries. This is not about supporting individual projects but about using a city-level element system and organizational capacity to turn open source into replicable and promotable industrial infrastructure.

**3.3.2.2 Shanghai: institutional leadership, a high-level international position, coordinated ecosystem efforts**

Shanghai is one of the core cities for AI development in China. Its above-scale (size-designated) AI industry is expected to exceed RMB 550 billion for the year, growing by more than 30%\[29\], and it has formed a full-chain system covering foundational algorithms, large model R&D, chip design, smart terminals and industry applications. It began to lay out directions such as large models, AI chips, embodied AI and autonomous driving early, and has brought together a group of nationally influential innovators including MiniMax, StepFun, SenseTime and Shanghai AI Laboratory. Unlike cities that excel at the spontaneous growth of corporate ecosystems, Shanghai places more emphasis on building an "infrastructure system" for AI development through institutional design and resource integration, giving it marked advantages in rule-making, platform organization and international cooperation.

**First, a strong capacity for institutional provision and systemic top-level design.** As a national central city and a front-runner of reform and opening up, Shanghai has considerable capacity for institutional innovation and policy coordination. It was early to issue an AI action plan in 2018 and has kept iterating its policy framework, forming a fairly complete institutional system for computing power layout, the marketization of data assets, mechanisms for opening up use cases and ethical governance standards. For the AI open source ecosystem, it has built a full-chain open source system through systematic institutional design. The *Shanghai Municipal Implementation Plan for Strengthening the Open Source System* sets quantified goals for 2027: "build one or two internationally influential open source communities, cultivate 100 open source commercialization companies, incubate more than 200 high-quality open source projects, and attract more than 3 million open source developers". It builds a complete policy system around five major projects: "laying the foundation of basic capabilities, cultivating excellent projects, attracting talent, popularizing culture and coordinating governance"\[30\]. This design — quantified goals, engineering-style implementation and coordinated governance — matches Shanghai's traditional strengths in urban planning, industrial policy-making and cross-departmental coordination, elevating open source ecosystem development from a spontaneous corporate activity to a strategic systems project for the city.

**Second, outstanding international connectivity and access to global resources.** The plan explicitly proposes "building an international AI open source community", promotes "first release on open source platforms" or "simultaneous global release" for projects, encourages high-quality open source projects to go global, and provides concentrated policy support in cross-border finance and professional services. At the same time, it relies on international platforms such as the World AI Conference (WAIC) and the Global Developer Pioneer Conference to advance international AI cooperation and open sharing, encouraging companies to integrate into the global open source ecosystem. This path makes full use of Shanghai's institutional advantages and brand effect as a window on reform and opening up and a center of international exchange, upgrading the AI open source ecosystem from a local technology community to an international innovation hub connecting developers worldwide**.**

**Third, strong ecosystem-organizing capability, driving the transition from technology community to industrial cluster.** Through park planning, industry funds, leading platforms and collaboration with research institutions, Shanghai integrates scattered resources into a systematic structure. Carriers such as the Mosu Space in Xuhui Riverside and Zhangjiang AI Island are typical practices that organize innovation actors through spatial form. On the one hand, Shanghai's policies have quickly rolled out the "Super Individual 288" program, which aims to screen 288 hard-technology projects within three years and to build 10 OPC communities, expanding the base of innovators\[31\]; on the other hand, it relies on open source communities to hold open source challenges, developer competitions and roadshows, helping high-quality teams start and grow businesses in Shanghai; it also promotes the evaluation and recognition of the value of open source assets, using capital to amplify the scale of innovation. This full chain of community discovery, institutional absorption and capital amplification reflects Shanghai's ecosystem-organizing strengths in financial capital, professional services and industrial park operations, making open source not merely the opening up of technology but an important mechanism for the efficient allocation of industrial factors and business model innovation.

**3.3.2.3 Shenzhen: corporate innovation as the driver, hardware and software in concert, public platforms as support**

Shenzhen is one of the Chinese cities with the greatest market vitality and density of corporate innovation in AI, showing strong corporate drive, strong hardware synergy and strong market conversion. Its core AI industry has now passed RMB 360 billion and brings together more than 2,800 companies\[32\], forming a complete system covering chip design, algorithm R&D, smart terminals, robots, drones and industry solutions. It has outstanding strengths in smart hardware, embodied AI, autonomous driving and industrial robots, and is home to globally influential technology companies including Huawei, Tencent, DJI and UBTECH.

The core logic of Shenzhen's AI development is corporate leadership and industry-chain collaboration, using highly market-based mechanisms to drive the rapid productization and scaling of technology. Building the AI open source ecosystem is deeply embedded in this overall logic.

**First, driven by private technology companies, with policy helping open source collaboration.** Shenzhen has a high share of private enterprise and a dense population of technology companies, short innovation decision chains and active capital markets; leading companies have built vertically integrated capabilities in chips, operating systems, cloud platforms and terminal devices, enabling AI to complete a closed loop of "technology R&D — product validation — scaling" within the corporate system. On this basis, the Shenzhen government gives a clear direction of "encouraging the open-sourcing of AI software", incentivizing leading companies to take the lead in tackling technology and building ecosystems by supporting the creation of source innovation centers and high-end exchange platforms; it markedly lowers the survival threshold for small and medium-sized enterprises through affordable computing vouchers, corpus vouchers and model vouchers, industry funds and talent subsidies; and by strongly encouraging open source, building open communities and platforms, and opening up government use cases, it provides a rich set of collaborative innovation interfaces and shared resources among leading companies, small and medium-sized enterprises, universities and developers. The goal is a virtuous cycle in which large companies build the ecosystem, small companies innovate quickly and developers all take part\[31\].

**Second, a complete electronics industry chain with a distinct AI+hardware open source character.** Shenzhen is a global center of electronic information manufacturing with a highly complete supply chain and a mature hardware ecosystem; from chip design, sensor manufacturing and module assembly to complete-device production, its industry-chain support is strong and its response times fast, allowing AI to be embedded quickly into terminal products and forming integrated "algorithm + hardware + use case" solutions. The government has made clear that it will "seize the opportunity of the on-device AI explosion and take the new track of the 'intelligent connection of everything'", building benchmark and demonstration applications around smart hardware, robots, smart homes and drones. It has also established Dagongfang AI Hardware OPC Hub, the world's first AI hardware OPC community, aiming to become the preferred destination for AI hardware "super individuals" worldwide\[31\].

**Third, a high degree of marketization, but basic research and original platform capabilities still need strengthening, so policy focuses on "closing gaps in public capabilities".** Shenzhen's strengths lie in industrial efficiency and commercial conversion, but it lags Beijing and Shanghai in basic research resources, the number of top universities and the density of national research platforms, which tends to produce strong short-cycle product iteration and weak long-term foundational accumulation. Shenzhen therefore addresses the shortfall in incentives for long-term, high-risk R&D with measures such as "investing up to RMB 300 million a year to strengthen support for basic research and technology breakthroughs" and "building key laboratories for artificial intelligence"; and it closes gaps in public capabilities with measures such as "supporting the creation of the Source Innovation Center for the Domestic Artificial Intelligence Ecosystem", providing migration and adaptation subsidies, "vigorously building public technology service platforms", "cultivating the open source ecosystem" and opening up application use cases\[24\]. Within this framework Shenzhen both ensures the rapid deployment and replication of technology and provides stable public support for the accumulation of foundational capabilities.

**3.3.2.4 Hangzhou: high-tolerance innovation, strong ecosystem-style empowerment, platform clusters advancing together**

Hangzhou is one of the typical cities where China's AI industry and open source ecosystem develop in concert. [In 2024, the revenue of Hangzhou's core AI industry passed RMB 300 billion, with more than 700 above-scale core enterprises](http://szjj.china.com.cn/2026-01/29/content_43345694.html), and it has formed a complete chain from basic computing power and model R&D to industry applications. It performs well in open source large models, "AI+ digital economy" and "AI+ government". Innovators such as DeepSeek and Unitree keep making breakthroughs in large models and embodied AI, while a group of AI ecosystem actors such as ModelScope and Datawhale have emerged as notable players in AI ecosystem operations and services. These results are shaped jointly by Hangzhou's industrial resource endowment, talent base and style of government governance.

**First, a high density of AI talent and a strong open source atmosphere.** Platform technology companies such as Alibaba, NetEase and Ant Group have trained and gathered a large number of computer science and engineering talents, forming a dense cluster of AI talent. These platform companies interact with universities and community organizations (such as ModelScope and Datawhale), fostering a comparatively strong open source culture and providing continuous talent supply and organizational capacity for model R&D, toolchain development and application innovation.

**Second, a highly active and tolerant innovation environment.** The added value of Hangzhou's tertiary sector accounts for about 73% of GDP, the digital economy accounts for 29.5% of GDP, and [private enterprises account for about 90%](https://www.nbd.com.cn/articles/2025-02-19/3757685.html#:~:text=2023%E5%B9%B4%EF%BC%8C%E6%B7%B1%E5%9C%B3%E7%9A%84%E5%AD%98%E7%BB%AD%E5%95%86%E4%BA%8B%E4%B8%BB%E4%BD%93%E8%BE%BE422.6%E4%B8%87%E6%88%B7%EF%BC%8C%E5%95%86%E4%BA%8B%E4%B8%BB%E4%BD%93%E6%95%B0%E9%87%8F%E5%92%8C%E5%88%9B%E4%B8%9A%E5%AF%86%E5%BA%A6%E5%)\[34\]; livestream e-commerce, fintech and consumer industries are well developed. This has created an economic environment with a high degree of marketization, short decision chains and relatively active capital. Companies respond quickly to technological innovation and have a relatively high tolerance for risk, which helps technology-based startups try and iterate quickly in their early stages.

**Third, a government that emphasizes service and ecosystem cultivation.** The Hangzhou municipal government adheres to the idea that "the government provides the conditions, firms do the growing", emphasizing market leadership with government guidance and shaping a stable business environment in which companies are left undisturbed and every request is answered\[35\]. Its policy instruments — building park carriers, clusters of industry funds, the issuance of computing and model vouchers, and opening up use case lists — lower the cost of innovation for companies. On platforms such as Zijingang Sci-Tech City and China Cloud Valley it explores computing support mechanisms, adding special funds and industry fund investment to guarantee the factors companies need at different stages of development. Once the ecosystem foundation was in place, policy documents began to explicitly rely on leading platforms, strengthening their function as city-level infrastructure and amplifying the ecosystem hub effect of leading platforms. ModelScope is a case in point: in its early years, from 2022 to 2024, Hangzhou's AI policies were organized around broad directions such as "foundation models, computing power, data assets and application use cases", encouraging greater cultivation of the model open source ecosystem and rewarding companies that contributed to communities, but ModelScope was not yet treated as a single lever. In 2025 the city explicitly supported building an internationally leading open source community on the basis of ModelScope, and backed it with computing vouchers, developer center subsidies and open source contribution awards, further consolidating its position as a city-level open source infrastructure hub\[36\].

**3.3.2.5 Suzhou: strengthening use-case-driven development, cultivating the OPC ecosystem, building an application hub**

Suzhou's AI industry continues to accelerate, showing steady growth in industrial scale, deep use-case applications and an active atmosphere for innovation and entrepreneurship. From January to August 2025, the AI industry generated revenue of RMB 247.2 billion, up about 18.7% year on year, and more than 60 AI-related industrial carriers have been built, bringing together 2,500 upstream and downstream companies\[37\]. An industrial system covering algorithm applications, smart equipment, industrial vision and data services has taken shape. Unlike cities led by foundation model R&D, Suzhou's AI path emphasizes "AI+ Manufacturing" and "AI+ industrial upgrading", highlighting the ability to deploy technology in production and pushing AI deep into the real economy. This pattern of development stems from Suzhou's industrial structural advantages, and at the same time brings new structural challenges.

**First, a huge manufacturing base, which determines the application orientation of AI development.** Suzhou has long ranked among the top cities in China for gross industrial output, with complete industrial clusters in electronic information, high-end equipment, biomedicine and new materials. A large number of above-scale industrial enterprises constitute a dense set of use cases, so AI is deployed first in quality inspection, equipment maintenance, production scheduling and supply chain optimization. Suzhou's AI companies tend to enter the market as solution providers and commercialize by solving specific production problems. This path is stable and pragmatic, but it leans toward deepening vertical use cases rather than breakthroughs in general-purpose technology.

**Second, strong industrial collaboration, but original technology and platform ecosystems are still relatively weak.** Suzhou has a complete industrial support system and an export-oriented economic structure, with strong engineering integration and system deployment capabilities. However, it still lags Beijing, Shanghai and Hangzhou in general-purpose large model R&D, open source community influence and the concentration of top algorithm teams. The number of AI companies is growing quickly, but leading model companies and open source ecosystem platforms with national influence remain limited. This means Suzhou faces the challenge of upgrading from use-case embedding to technology leadership.

**Third, urgent demand for upgrading traditional industries, which forces innovation in venture forms and policy models.** As manufacturing moves into a phase of intelligent, flexible upgrading, small and medium-sized enterprises have growing demand for AI technology, but their own R&D capacity and organizational scale are limited. The traditional asset-heavy team-based venture model struggles to meet the technological innovation needs of a large number of niche use cases quickly. How to lower the barrier to innovation and encourage more technology-oriented individuals to take part in industrial upgrading has become an important question for Suzhou.

Against this background, the Suzhou municipal government has made the emerging OPC venture form a focus of its planning, aiming to create a new paradigm for innovation and entrepreneurship in the AI era. The 2025 Jiangsu AI Innovation and Development Conference and the first AI OPC Conference were held in Suzhou\[38\], emphasizing a new organizational form in which "an individual plus AI employees is a company", the strategic positioning of Suzhou as the city of choice for OPC entrepreneurs, and explicit goals for 2028: build 30+ OPC communities, cultivate 1,000+ OPC companies and attract 10,000+ OPC talents, backed by systematic support policies. The government has built a full-chain support system around core elements of technology, funding, use cases, talent and the ecosystem. On space, it is laying out more than 1 million m² of OPC carriers across the city, offering one to three years of rent-free workstations on a move-in ready basis. On computing power, it issues computing vouchers, model vouchers and data vouchers, with computing subsidies of up to RMB 2 million per year. On funding, it provides concrete financial support, with individual awards of up to RMB 50 million, a youth entrepreneurship fund cluster of over RMB 1 billion, and direct investment of up to RMB 50 million in leading talents. On talent, it opens green channels for household registration, housing and education, with 1,000 talent apartments. On use cases, it opens up 150+ government and enterprise use cases in industrial manufacturing, the historic city's culture and tourism, industrial design and digital cultural creativity. On services, it has set up a dedicated OPC section within one-stop government services, enabling company registration, policy applications and industry matchmaking to be handled entirely online\[39\]. With a model of "you bring the ideas, we provide the full backstop", Suzhou aims to be the best choice for OPC entrepreneurs.

**3.3.2.6 Zhuzhou: going deep into niche use cases, attracting specialized talent, building a distinctive ecosystem**

As an important industrial city, Zhuzhou is actively advancing its AI industry, showing clearly industry-use-case-driven development, steady growth in industrial scale and the rapid construction of innovation carriers. In recent years, Zhuzhou has deployed AI use cases around its leading industry chains and publicly released its first list of enterprise application use cases for "AI+ Manufacturing", covering product R&D, process optimization, production management and operations and maintenance services across the whole value chain in rail transit, aerospace and cemented carbide, opening up 51 specific use case requests in total\[40\] and building a bridge between AI technology and concrete manufacturing problems. In industrial software and embodied AI, Zhuzhou is accelerating the cultivation of demonstration enterprises and solutions to drive large-scale deployment of AI in industrial manufacturing. Zhuzhou's path is closely tied to its deep industrial base and its need to upgrade and transform.

**On the one hand, a large traditional manufacturing base and a complete industry chain constitute a real battlefield for AI applications.** Zhuzhou has competitive industrial clusters in rail transit equipment, aero engines, cemented carbide and new materials, and is one of China's important manufacturing bases; these industries have sustained and specific demand for AI technologies such as high-precision inspection, production scheduling optimization and intelligent operations and maintenance. This industrial base provides rich use cases and broad space for the deployment of AI technology.

**On the other hand, industrial innovation actors are relatively small in number and talent aggregation has yet to strengthen.** Although Zhuzhou promotes AI applications among local industrial enterprises, high-end AI R&D talent, leading technical teams and cross-sector innovators are still relatively scarce. Its current ecosystem depends more on its grasp of manufacturing pain points, and no obvious clustering effect has yet formed in terms of nationally influential AI companies and innovation platforms.

Against this background, Zhuzhou keeps strengthening policy guidance and building innovation carriers, promotes deep integration of AI with industry, and actively develops its talent ecosystem and innovation communities.

The Zhuzhou municipal Party committee and government, together with Datawhale, are promoting the Huamao AI Community\[41\], which is rooted in the city's industrial character, takes young innovators and industrial technology teams as its main body, focuses on vertical AI fields and builds an innovation ecosystem community that integrates online and offline. The community, centered on Wanfeng Lake, brings together a Learning Center, laboratories, an industrial park and a media influence center, aiming to create an AI innovation source, a validation ground for vertical applications and an influential AI brand community\[42\]. The "AI+ Manufacturing" use case request list and the accompanying policy support list released at its launch ceremony use real use cases and precise policies to build an ecosystem rainforest that attracts AI innovation talent\[43\]. Brand events such as the "Tianyuan Cup" Smart Industrial Software Innovation Application Competition are also used to gather talent and promote industry, with a package of factor guarantees covering computing networks, industry funds, special policies and government services, forming an integrated mechanism of "use-case-driven development, platform support, event-based aggregation and empowerment through factors" that accelerates the integration of AI and manufacturing\[44\]. On talent development, Zhuzhou Vocational College of Science and Technology has worked with industry-leading companies to establish an AI college, developing highly skilled talent closely aligned with industry needs through a university-enterprise collaborative model\[45\]. Overall, by building an AI ecosystem in which "use cases drive, talent supports and the ecosystem is cultivated", Zhuzhou is providing a practical example of AI transformation for industrial cities.

**3.4 China–US comparison of the AI open source ecosystem**

**3.4.1 Differences in development goals: application-driven in China, market-driven in the US**

The development goals of the Chinese and US AI open source ecosystems differ markedly. China's AI open source ecosystem development is not confined to technological innovation itself but is embedded in national strategies for industrial upgrading and structural transformation, emphasizing the use of open source to lower the barrier to innovation and widen the radius of technology diffusion, thereby empowering the real economy, cultivating new business forms and absorbing innovative employment. Since the *New Generation Artificial Intelligence Development Plan* was issued\[46\], AI has been positioned as a core engine of high-quality economic development, and local governments generally include open source model platforms, toolchains and computing infrastructure in industrial cluster building and digital economy planning. At the same time, against the backdrop of intensifying external technological constraints, the open source ecosystem has also been given the strategic meaning of "self-reliance and controllability" and supply chain security, becoming an institutional instrument for reducing the risk of technological lock-in and strengthening systemic resilience. By contrast, the United States is on the whole more market-driven. Its policy frameworks, such as the *AI Action Plan*\[47\] and Executive Order 14179\[48\], focus on consolidating global technological leadership through R&D investment, risk governance frameworks and standard-setting rather than directly guiding industrial deployment. The US government emphasizes shaping the innovation environment and global rules, strengthening global influence through institutional design, international standards and technology assessment systems; companies, for their part, use open source to build developer ecosystems and de facto standards, creating technological path dependence and a global diffusion effect. Overall, China emphasizes "open source as infrastructure for industrial development and security", while the United States emphasizes "open source as a strategic tool for technological leadership and rule-shaping".

**3.4.2 Differences in development paths: application prosperity in China, full-stack control in the US**

In large models, there is a certain technological gap between China and the United States. Mainstream US companies such as OpenAI and Google usually choose to commercialize model weights and their most advanced capabilities as closed source, while Chinese models (such as Alibaba's Qwen series and DeepSeek) mainly adopt an open source strategy to accelerate iterative innovation and derivative diffusion. China currently performs strongly in engineering implementation, efficiency optimization and localized innovation\[49\], but still lags the United States in leading entirely new AGI paradigms (such as continual learning, memory and multimodality). At Tsinghua University's AGI-Next Frontier Summit in 2026, experts noted that the gap persists and may even be widening\[50\].

In large model software, the United States shows full-stack control from the underlying chips to the application layer, and has formed de facto standards in fields such as compilers and inference frameworks through extremely high adoption. China, by contrast, shows a pattern of "closed source at the foundation, open source at the application layer": Chinese cloud vendors open-source relatively little of the engineering capability they have accumulated in training platforms, inference platforms and cloud service infrastructure, and the open source ecosystem currently flourishes mainly at the application level, with localized activity in areas such as reinforcement learning and fine-tuning, reflecting China's strengths in engineering execution and use-case understanding. This paper carries out a statistical analysis based on the 114 globally influential open source projects in *The Open Source Development Ecosystem for Large Models: Landscape and Trends*\[51\], and the results show this situation directly: at the chip layer, the computing layer and the inference and training system layer, Chinese open source projects lag the United States considerably in both number and influence (the OpenRank metric). These areas are the foundation of AI commercialization; they directly determine model operating efficiency, cost and concurrency, and they are characterized by long development cycles, slow commercial returns, high technical moats and strong ecosystem lock-in effects. The current situation of closed source at the foundation in China, while conducive to greater engineering efficiency and stronger commercial barriers, easily leads to insufficient influence over technical standards and weak ecosystem spillover capacity, resulting in risks of technological dependence and constrained innovation.

**3.4.3 Differences in ecosystem models: platform-centered and use-case-driven development in China; a more balanced mix in the United States**

Based on the same 114 globally influential open source projects\[50\], a further analysis of ecosystem models in open source software for large-scale AI models shows that **the single-organization-led model** is the predominant ecosystem type in both China and the United States. China, however, exhibits a more pronounced dual pattern comprising the single-organization-led model and **the peripheral-ecosystem model,** whereas the four ecosystem models are more evenly distributed in the United States. Together, **the standard-exploration model** and **the neutral-governance model** account for approximately 40% of US projects, a substantially higher share than in China.

This distribution is closely associated with the United States' advantage in exercising control across the entire AI value chain, particularly over foundational standards. Standard-exploration and neutral-governance projects typically explore technical standards, compete to establish de facto standards, and provide infrastructure for cross-organizational collaboration. They tend to operate at the level of model frameworks, toolchains, protocols, and interface specifications—areas characterized by "high long-term value but limited short-term monetization potential." These projects are important sources of ecosystem stability and of the capacity to shape technological development and standards.

China, for its part, has advantages in use cases and institutions. The efficient decision-making and resource allocation of the single-organization-led model help companies form solutions quickly and close the gap under conditions of constrained computing power, intense market competition and a limited window for industrial upgrading; it is an effective way to organize "catch-up innovation". The peripheral-ecosystem model, drawing on rich use cases and engineering execution, helps diffuse AI capabilities into real business settings and creates a virtuous cycle in which application demand feeds back into technical improvement. However, these two models struggle to accommodate the demands of multiple parties and deep co-building, limiting the accumulation of general-purpose capabilities and the formation of de facto standards.

**3.4.4 Differences in the talent landscape: China's growing talent base and the mature US talent ecosystem**

The United States accounts for the largest share of the world's top AI developer talent, which is closely related to its strong ability to attract talent. According to MacroPolo's tracking, based on authors of papers presented at top AI conferences in 2022\[52\], 47% of the world's top AI researchers received their undergraduate degrees from Chinese universities and 18% from US universities; but at the career stage, about 42% of the top talent from China choose to work in the United States. China is the United States' biggest competitor for AI talent, yet only 12% of the most elite AI talent chooses to work in China — a very obvious gap. China is currently still catching up rapidly in terms of talent scale. According to Ant Group's open source mapping of the locations of about 120,000 developers of leading AI open source projects, US-based developers account for 37.4% and Chinese developers for 18.7%, about half the US share\[51\]. A report by the Liepin Big Data Research Institute further shows that in the first half of 2025 China's AI talent gap exceeded 5 million people, with technical talent especially scarce\[53\].

At the same time, the United States has a deeply rooted open source culture, and open source contributions are widely recognized in career advancement, encouraging technology professionals to contribute to open source projects. By contrast, in China, the visibility of individual open source contributions in the external labor market—and the extent to which they can be translated into financial returns—remain uncertain. Emerging roles in open source advocacy and developer relations (DevRel) are still taking shape. Professionals responsible for open source program and community operations often lack role definitions and competency frameworks recognized across the industry; when moving laterally between companies, they may therefore need to explain the value of their experience anew. Together, these factors have, to some extent, constrained the thriving of China's open source AI ecosystem.

**3.4.5 Differences in governance: ecosystem cultivation in China versus institutional maturity in the United States**

Compared with China, US foundations and corporate open source program offices were established earlier, and their institution building and ecosystem development are more mature.

**On foundation building**, mainstream US open source foundations were established earlier and are relatively mature, having formed stable and replicable governance and incubation models. Typical examples include the Apache Software Foundation (established 1999), the Linux Foundation (2000) and the Cloud Native Computing Foundation (CNCF, 2015). Over long practice, these foundations have accumulated operating mechanisms characterized by "community self-governance, separation of powers and responsibilities, and institutions first". **In organizational structure**, a "three-tier governance architecture"\[54\] is common: board of directors — technical governance committee — project working units. The board does not directly intervene in technical decisions on specific projects. The technical governance committee holds key technical decision-making power and is accountable to the community; it is usually formed through contributor elections or community consensus rather than being appointed by the board or funders. This structural design of horizontal separation of powers and vertical autonomy is an important institutional basis for maintaining technical neutrality and community vitality over the long term. **In assessment and evaluation mechanisms**, US open source foundations have generally established transparent indicator systems covering the full project lifecycle, used to assess the conditions for a project's entry, promotion and exit. These indicators embody the combined logic of "community health + governance maturity" rather than the traditional project management logic of "project results + resources invested". In CNCF's case, the dimensions of its graduation assessment include whether the governance structure is sound, whether core maintainers have multi-organization backgrounds, community activity, contributor diversity, technical security and compliance capability, and use of the project in real production environments\[55\].

China's first foundation dedicated to open source, the OpenAtom Foundation, was established in 2020. It likewise has a three-tier governance structure comprising a Board of Directors, a Technical Oversight Committee (TOC), and specialized committees. The foundation describes its role as an "incubator, connector, and multiplier," although its criteria for project advancement and retirement are still being refined.

**At the corporate level, in terms of open source management,** companies that incorporate open source into their strategic agenda typically establish an open source program office (OSPO) to coordinate internal open source collaborations, develop strategies for external open source engagement, oversee compliance, and manage relationships with open source communities. Leading US technology companies, including Microsoft, Google, and Meta, established OSPOs relatively early, whereas leading Chinese technology companies, such as Alibaba and Huawei, did so relatively later. Although OSPOs vary in their organizational positioning and structure, their primary purpose in both countries is to support the company's overall strategy. A company's business structure, strategic priorities, and engineering culture determine where its OSPO sits within the organization, how heavily it is resourced, and which functions it prioritizes. No single model is inherently superior.

From the perspective of the broader ecosystem, however, corporate OSPOs in the United States operate within a dense external support network comprising foundations, third-party tools, evaluation frameworks, and consulting services. Companies can therefore draw on a wider range of established models and practices in institutional design, performance measurement, and governance. By contrast, corporate OSPOs in China rely more heavily on in-house experimentation, while independent third-party services and standardized tools remain at an early stage of development.
